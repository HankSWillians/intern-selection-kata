## Convenciones

- Cada requerimiento tiene un identificador estable: `RF-<nn>` para los funcionales, `RNF-<nn>` para los no funcionales, `HU-<nn>` para las historias y `CP-<nn>` para los casos de prueba. Si uno se elimina, su número no se reutiliza.
- **⚠️ Por confirmar:** duda que no está resuelta. No se implementa sin resolverla.
- Las specs se escriben en español. Los nombres en el código siguen la regla del [CLAUDE.md](../CLAUDE.md): en inglés.
- El seguimiento de los casos de prueba (Sin ejecutar, Pasó, Falló) se lleva en el documento [Requerimientos – Plataforma Básica de Selección de Practicantes](https://claude.ai/artifact/PGKebkBttg4XuL8wnv62Ev). Para nombres técnicos (tabla, campos, endpoints) y stack, manda la versión de este repositorio.
